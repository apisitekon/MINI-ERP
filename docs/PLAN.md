# แผนผลิตภัณฑ์ & การตลาด — Thai Freelance ERP Lite

> อัปเดต: 2026-09-25 · เจ้าของ: 9Modle · เอกสารฉบับเต็ม (มีตารางคู่แข่ง/แหล่งอ้างอิง) อยู่ใน Claude Docs "แผนการตลาด Thai Freelance ERP Lite"

## 0. หลักการ: ใช้เองก่อน แล้วขายไปด้วย (dogfooding)

- ใช้ระบบนี้ออกบิลงานจริงของตัวเองทุกงาน — ทุกจุดที่ติดขัด = backlog
- เปิดให้คนอื่นใช้ฟรีคู่ขนาน เก็บ feedback จากผู้ใช้จริง 10–20 คนแรก
- เปิดเก็บเงินเมื่อ (1) ตัวเองใช้ครบรอบ 1 เดือนโดยไม่ต้องกลับไปใช้ Excel และ (2) มีผู้ใช้ภายนอก ≥ 20 คนที่ออกเอกสาร ≥ 3 ใบ

## 1. Positioning

**"ระบบหลังบ้านของฟรีแลนซ์"** — รับงาน → ออกบิล → เก็บเงิน → ภาษี → รู้ว่างานมาจากไหนคุ้มที่สุด

Tagline ที่แนะนำ: *รู้ว่างานไหนทำเงิน · ออกบิลเสร็จใน 1 นาที · สิ้นปีรู้ว่าได้ภาษีคืนเท่าไหร่*

ไม่ทำ "one stop ทุกอย่าง" และไม่แข่งเป็นโปรแกรมบัญชี (FlowAccount/PEAK)

## 5. การตลาด (สรุป)

- **Funnel:** SEO/TikTok/กลุ่ม FB → Checklist ฟรี (LINE OA) → สมัคร Free → ออกบิลแรกใน 7 วัน → Pro เมื่อต้องการฟีเจอร์ภาษี/วิเคราะห์ → แนะนำเพื่อน (ได้ฟรี 1 เดือน)
- **Digital products:** Checklist ฟรี · Template สัญญา/SOW 199 · E-book ภาษีฟรีแลนซ์ 249 · Mini-course 990 (แถม Pro 1 ปี) · Workshop องค์กร 15–30k
- **Partner:** Fastwork (เนื้อหา), iTAX (ภาษีส่วนบุคคล), สำนักงานบัญชี (affiliate 30% ปีแรก)
- **เรื่องเล่าจาก dogfooding:** โพสต์ "ใช้ระบบตัวเองออกบิลจริง เดือนที่ N" — ตัวเลขจริงจาก dashboard ช่องทาง

## 7. หมายเหตุทางเทคนิค: หลายธุรกิจ

- ข้อมูล: `users/{uid}.businesses = [{id,name,taxId,phone,promptPay,address}]`, `defaultBusinessId`; ฟิลด์เดิม `businessName…` ถูก mirror จากธุรกิจค่าเริ่มต้น (หน้าเก่ายังใช้ได้)
- บัญชีเดิมที่มีข้อมูลธุรกิจเดียว ถูกแสดงเป็นธุรกิจ id `default` อัตโนมัติ (ไม่ต้อง migrate)
- เอกสารเก็บ `businessId`; หน้า print ใช้ธุรกิจนั้น หรือ fallback เป็นค่าเริ่มต้น
- ขีดจำกัด: `businessLimit` ที่แอดมินตั้ง > Pro 3 > อื่น ๆ 1 — บังคับใน `firestore.rules` (ต้องแก้คู่กับ `PLANS` ใน `js/firebase-config.js`)
- บัญชีที่ถูกลดแพ็กเกจ: ข้อมูลยังอยู่ แก้/ลบได้ แต่เพิ่มไม่ได้ และเลือกออกเอกสารได้เฉพาะ N ธุรกิจแรก (ค่าเริ่มต้นก่อน)
